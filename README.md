# Music Player Experiment

This project is a test developed with Next.js as part of my experiments while working towards building a music player.

### Features
- Local audio playback.
- Real-time audio visualization using the Web Audio API and Canvas.
- Synchronized lyrics using the [LRCLIB API](https://lrclib.net/).

### Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to use the application.

**Note:** This is just an experiment and a work in progress. The goal is to use what I learn here to build a complete music player in the future.
